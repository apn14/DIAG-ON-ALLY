# Codex Instructions

You are building Garage AI Diagnostic, a mobile app for AI-assisted car troubleshooting.

## Stack

- Expo React Native
- TypeScript
- Expo Router
- React Native Paper for UI components
- AsyncStorage for MVP local storage
- Node.js Express backend later

## Rules

- Keep the app simple and working.
- Use TypeScript types for vehicle profiles and diagnostic summaries.
- Do not expose API keys in frontend code.
- Use mock AI responses until the backend is added.
- Prioritize automotive safety warnings.
- Break UI into reusable components.
- After each task, explain what files changed and how to test.

## Design Style

Dark automotive interface.
Rounded cards.
High contrast.
Simple mobile-first layout.
No unnecessary animations.
