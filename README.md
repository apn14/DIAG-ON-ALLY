# Garage AI Diagnostic

Mobile MVP for AI-assisted car troubleshooting.

## Current Scope

- Expo React Native TypeScript app in `mobile/`
- Expo Router navigation
- React Native Paper UI
- AsyncStorage-backed vehicle and report storage
- Mock diagnostic assistant responses
- Mock structured diagnostic summaries

Backend and OpenAI integration are intentionally not implemented yet.

## Run

```bash
cd mobile
npm install
npm run start
```

Use Expo Go, an emulator, or `npm run web` to preview the app.
